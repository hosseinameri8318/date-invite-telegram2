سایت دعوت دیت — نسخه اتصال آپلود عکس به تلگرام

محتویات پروژه:
- public/index.html: فایل وب‌سایت
- netlify/functions/send-photo.mjs: تابع سمت سرور برای ارسال عکس به تلگرام
- netlify.toml: پیکربندی Netlify

پیش‌نیاز تلگرام:
1. در تلگرام گفت‌وگوی خود ربات (@hoossein_date_bot) را باز کنید و Start بزنید. ربات باید قبلاً با BotFather ساخته شده باشد.
2. توکن ربات را از گفت‌وگوی BotFather بردارید، اما آن را در فایل‌های سایت، GitHub یا چت منتشر نکنید.

انتشار با Netlify (نسخه دارای تابع سرور):
1. پروژه را به‌صورت کامل در یک مخزن GitHub بارگذاری کنید؛ پوشه netlify و فایل netlify.toml را حذف نکنید.
2. در Netlify گزینه Add new site / Import an existing project را انتخاب کنید و مخزن GitHub را متصل کنید. Build command را خالی بگذارید؛ Publish directory در netlify.toml روی public تنظیم شده است.
3. در Netlify از Site configuration / Environment variables (یا Project configuration / Environment variables) این دو متغیر را اضافه کنید:
   TELEGRAM_BOT_TOKEN = توکن دریافتی از BotFather
   TELEGRAM_CHAT_ID = 8484626228
   این مقادیر باید در تنظیمات میزبان باشند، نه داخل HTML یا GitHub.
4. بعد از ثبت متغیرها، سایت را دوباره Deploy کنید.
5. سایت منتشرشده را باز کنید و یک عکس آزمایشی کوچک با حجم کمتر از ۴ مگابایت بفرستید. در صورت موفقیت، عکس باید در گفت‌وگوی شما با ربات ظاهر شود.

نکات:
- آپلود عکس در نسخه وب به تابع سمت سرور ارسال می‌شود و سپس با Telegram Bot API به چت مشخص‌شده فرستاده می‌شود.
- سقف این نسخه ۴ مگابایت است تا درخواست از محدودیت payload توابع Netlify عبور نکند.
- توکن ربات را به هیچ‌کس ندهید. اگر افشا شد، از BotFather آن را باطل/تعویض کنید.
- ربات تنها وقتی می‌تواند پیام خصوصی بدهد که کاربر قبلاً گفت‌وگوی ربات را آغاز کرده باشد.
- برای بازبینی، متن صفحه می‌گوید عکس به تلگرام حسین فرستاده می‌شود.
